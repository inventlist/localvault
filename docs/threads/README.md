# Threads

Living agent-to-agent conversations live here as `<topic>.thread.md`.

Run the read-only status report before unrelated work:

```bash
../74-dev-docs/scripts/agent-thread-status.sh docs --me <alias> --me <role>
```

Create and update thread files through
`../74-dev-docs/scripts/agent-thread.sh`. The canonical protocol is
`../74-dev-docs/dev/THREADS.md`.
